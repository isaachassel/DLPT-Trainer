HUGGING FACE REPAIR - START HERE
================================

The earlier browser upload flattened the app's folders and paired several
filenames with the wrong contents. This package includes a safe uploader that
preserves the exact repository structure.

1. Extract the entire ZIP. Do not run anything from inside the ZIP preview.
2. Open the extracted folder.
3. Double-click UPLOAD_TO_HUGGINGFACE.bat.
4. When asked, type REPLACE.
5. Paste a Hugging Face WRITE token. The token is hidden, used only for this
   upload process, and not saved by the script.

Create or inspect tokens here:
https://huggingface.co/settings/tokens

Target Space:
https://huggingface.co/spaces/alsubij/Multi-Language-DLPT

The uploader verifies the local Space metadata and required folder structure
before uploading. It then replaces the corrupted remote file tree in one
versioned commit. Hugging Face automatically starts a new build afterward.

If Windows says Python is missing, install Python 3.11 or newer from:
https://www.python.org/downloads/windows/

During Python installation, select "Add Python to PATH", then run the BAT file
again.

AFTER THE SPACE REBUILDS - FRESH AI v1.7.8
===========================================
For the recommended all-free GenAI route, open the Space's
Settings > Variables and secrets and add:

  GEMINI_API_KEY   (free Google AI Studio API key)
  GROQ_API_KEY     (keep your existing Groq key)
  HF_BANK_TOKEN    (keep/use a write token for the private generated bank)

Recommended variables:
  GENERATION_PROVIDER=gemini_then_groq
  VERIFICATION_PROVIDER=auto
  ENABLE_HF_INFERENCE=false
  PREFER_GEMINI_IF_AVAILABLE=true

If your Space still has GENERATION_PROVIDER=hf_then_groq, v1.7.8 automatically
promotes Gemini when GEMINI_API_KEY is present, but changing the variable to
`gemini_then_groq` makes the intended routing explicit.
