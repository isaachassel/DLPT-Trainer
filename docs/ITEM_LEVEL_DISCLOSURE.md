# Item-Level Disclosure — v1.2.9

## Policy

- Training Mode reveals item levels with configured passage feedback or in the final report.
- Adaptive Diagnostic and Full CA Simulation do not reveal item levels while a section is active.
- Completed final reports list the level metadata for every answered question, not only missed questions.

## Terminology

**Intended ILR X — provisional item level** means the item was authored, independently checked, and stored for that target band, but has not been empirically calibrated from sufficient response data.

**Approximately ILR X — empirically calibrated item difficulty** means the stored calibrated continuous difficulty is mapped to the nearest displayed ILR half-band. The original authoring target is retained when it differs.

Neither label is an official DLPT classification.
