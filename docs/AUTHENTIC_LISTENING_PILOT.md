# Authentic Russian listening pilot

Branch: `codex/authentic-listening-pilot`, based on the completed authentic
reading feature. No production manifest, live Space, WordPress page or ALES
branch was changed. No ElevenLabs credits or generation APIs were used.

## Imported material

Six authentic radio excerpts, 17 questions, approximately 196 seconds of
recorded speech. The supplied transcript-based targets are one 1+, three 2,
and two 2+ excerpts. The 17.7-second first clip has two questions; the others
have three. These remain **teacher-review drafts**, not calibrated items.

The supplied ZIP was the reading pack, with no listening JSON or Ogg files.
The listening adapter therefore parsed the supplied `listening_review.html`
and cross-checked it against `listening_review.md`. It did not execute the HTML
or invent missing questions, transcripts or media. Embedded MP3 bytes were
decoded from the HTML and preserved unchanged under content-hash filenames.

The native package lives at
`data/content_packs/ru-authentic-listening-pilot-01/package.json`.
The original HTML and Markdown are preserved byte-for-byte under `versions/v1/`;
the HTML contains answer keys and is an instructor artifact, never a diagnostic
client. Native records preserve stable passage/question/family IDs, original
caption wording, timestamps, every evidence span, option rationale, review
focus and attribution. The native question category maps the original skill
into the existing categories; the original skill remains in metadata.

Full MP3 decoding passed for all six files. On November 27, 2026, all six Commons
file pages and all six fixed caption revisions loaded. File-specific CC BY 3.0
notices and Commons CC BY-SA 4.0 caption notices were found; joined caption text
matched each fixed revision. See `source_verification.json` for hashes and
checks. These are document and decoding checks, **not an independent audition
or waveform comparison against the original Ogg**. Source wording and factual
claims are not independently certified.

## Local instructor preview

From the project root in PowerShell:

```powershell
.venv/Scripts/python.exe scripts/preview_listening_pack.py --port 7868
```

Open <http://127.0.0.1:7868/>. Choose a numbered excerpt and click **Open passage**.
Click **Play passage · two listens**; the existing demo playback controller
plays it twice with a beep between listens. Complete all visible questions,
then click **Finish preview and review**. Transcripts, keys, timed evidence,
raw correct/total, missed skills, and separate source/license credits appear
only after completion. No proficiency estimate is generated by this preview.
Unused question slots are hidden for the two-question excerpt.

The preview binds only to localhost. It serves only the local audio directory;
the native package, original review documents, secrets, Git and learner-storage
paths are blocked. It is not deployed and requires no provider credentials.

An optional local profile ID records exposure immediately on display. Reuse
that profile ID in a local diagnostic to avoid treating any version of that
passage family as fresh evidence. The anonymous hosted demo cannot identify
the same person across devices or origins. This matches the reading feature's
exposure limitation.

## Teacher review and activation

Use the **Approval rubric** in the archived `listening_review.md`. Listen at
normal speed before consulting captions. Check every caption against the
audio; pace, clarity, register, overlap and background sound; question
answerability from sound alone; unique best keys; distractor plausibility and
cross-question clues; and source reuse rights. Record reviewer identity,
date, corrections and agreed instructional level. The prior approval of
generated ElevenLabs voices does not approve these authentic excerpts.

Published final captions sometimes run a few hundredths of a second beyond
decoded audio duration. Original review timings are retained and the overrun
is recorded. Playback uses the actual media end, not caption timers; no
word-level alignment or precise caption accuracy is claimed.

After teacher approval, use the existing curator CLI, once per approved item:

```powershell
.venv/Scripts/python.exe scripts/curate_assessment.py validate --package data/content_packs/ru-authentic-listening-pilot-01/package.json
.venv/Scripts/python.exe scripts/curate_assessment.py approve --package data/content_packs/ru-authentic-listening-pilot-01/package.json --item ru-listen-pilot01-sotnikova --reviewer "Actual reviewer" --notes "Actual listening, caption, question, level and reuse review" --attest-reuse-rights
```

Approval copies the reviewed recording into `data/assessment/audio/`, records
the named dated decision in the active manifest and retains source attribution.
Restart locally to load it. Push/publish remains a separate user-authorized
step. Existing synthetic-audio release safeguards are unchanged; authentic
audio has a separate release path requiring approved reuse, complete separate
audio/caption credits, supported licenses and matching recording checksums.

## Reimport and revisions

Optional curator dependencies (not required by the hosted app):

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-content-import.txt
.venv/Scripts/python.exe scripts/import_listening_review.py --html "path/to/listening_review.html" --markdown "path/to/listening_review.md" --output data/content_packs/ru-authentic-listening-pilot-01/package.json
```

The adapter accepts the supplied review format, fails on mismatched keys,
choices, evidence or transcript, and validates all audio before publishing a
local draft package. Identical reimports do not duplicate content. Changed
submissions require `--version 2` (or higher), preserving previous original
files, packages and content-addressed recordings. Approved changes require a
higher content version and fresh review through the same curator rules.

## Assessment behavior and licenses

All questions remain attached to their passage; choice shuffling retains stable
option IDs in response records. The existing guessing and shared-passage
evidence model remains unchanged. Provisional labels are only instructional
routing estimates; this small seed pack is not a balanced or validated test.

After an assessment finishes, **Sources for your listening** credits the
speaker, broadcaster, date, Commons file, audio license (CC BY 3.0), fixed
caption revision/contributors and caption license (CC BY-SA 4.0), along with
excerpt/format changes and non-endorsement. Mixed reading/listening reports
use a neutral assessment heading. Attribution snapshots survive bank revisions.

Deployments exclude drafts and authoring documents. An approved deployment
retains source credits in the backend bank and `SOURCE_CREDITS.html` as well
as the end-of-assessment report. Captions retain their ShareAlike license;
the code's MIT license does not replace source licenses. Maintain the Protected
Space setting: a publicly downloadable backend source bank would disclose keys.

contains only the existing 66 approved items and 38 recordings, with no drafts.
